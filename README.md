# VoidSpam ESP v9 (Rivals)

Client-side ESP script (no server access).

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/jamironuss-art/voidspam-esp/main/VoidSpam_loader.lua"))()
```

Replace https://raw.githubusercontent.com/jamironuss-art/voidspam-esp/main/VoidSpam_loader.lua with the raw URL below. The loader is fully offline at runtime (libraries embedded).

## Files

- `VoidSpam_loader.lua` - ready-to-use shareable loader (base64 + loadstring)
- `VoidSpam_Linoria_v9.lua` - readable source
